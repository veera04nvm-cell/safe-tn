\# 🚗 Traffic Crash Prediction System



A machine learning-based system for predicting weekly traffic crashes to assist enforcement planning.



\## 📁 Project Structure



```

dashboard/

├── venv/                           # Virtual environment (don't modify)

├── data/                          # Data files

│   ├── traffic\_crash\_merged.csv   # Input data (you provide)

│   ├── weekly\_crashes\_enhanced.csv # Generated by model

│   ├── future\_predictions\_ml.csv   # Generated by model

│   └── model\_performance\_comparison.csv

├── scripts/                       # Python scripts

│   └── train\_model.py            # ML training pipeline

├── app/                          # Streamlit application

│   └── streamlit\_app.py          # Dashboard interface

├── images/                       # Generated plots

│   ├── feature\_importance.png

│   └── model\_comparison.png

├── requirements.txt              # Python dependencies

└── README.md                     # This file

```



\## 🚀 Quick Start



\### 1. Setup (First Time Only)



```bash

\# Navigate to your dashboard folder

cd path/to/dashboard



\# Activate virtual environment

\# Windows:

venv\\Scripts\\activate

\# Mac/Linux:

source venv/bin/activate



\# Install dependencies

pip install -r requirements.txt

```



\### 2. Prepare Your Data



Place your data file in the `data/` folder:

```

dashboard/data/traffic\_crash\_merged.csv

```



\### 3. Train the Model



```bash

python scripts/train\_model.py

```



This will:

\- Load and process your data

\- Train ML models (Random Forest, Gradient Boosting, Ridge Regression)

\- Generate predictions for the next 12 weeks

\- Save results to `data/` folder

\- Create visualizations in `images/` folder



\*\*Expected output:\*\*

```

✓ Data loaded: XXXX hourly records

✓ Created weekly records

✓ Training models...

✓ Model accuracy: 99%

✓ Files saved successfully

```



\### 4. Run the Dashboard



```bash

streamlit run app/streamlit\_app.py

```



Dashboard will open automatically at: `http://localhost:8501`

\## 🛠️ Troubleshooting



\### "File not found" error

\*\*Problem:\*\* Data file not in correct location

\*\*Solution:\*\* 

```bash

\# Ensure your data file is here:

dashboard/data/traffic\_crash\_merged.csv

```



\### "Module not found" error

\*\*Problem:\*\* Missing packages

\*\*Solution:\*\*

```bash

\# Activate venv first, then:

pip install -r requirements.txt

```



\### Dashboard won't start

\*\*Problem:\*\* Port already in use

\*\*Solution:\*\*

```bash

\# Use a different port:

streamlit run app/streamlit\_app.py --server.port 8502

```



\### Virtual environment issues

\*\*Problem:\*\* Can't activate venv

\*\*Solution:\*\*

```bash

\# Recreate virtual environment:

python -m venv venv

venv\\Scripts\\activate

pip install -r requirements.txt

```



\## 📈 Model Information



\*\*Algorithm:\*\* Ensemble of 3 models

\- Random Forest Regressor

\- Gradient Boosting Regressor  

\- Ridge Regression



\*\*Features Used:\*\*

\- Speed patterns (avg, std, deviation)

\- Traffic volume (NPMRDS data)

\- Congestion indicators

\- Temporal patterns (time of day, day of week)

\- Historical crash lags (1-12 weeks)

\- Rolling statistics



\*\*Performance:\*\*

\- Accuracy (R²): ~99%

\- Average Error (MAE): ~0.07 crashes

\- Prediction Horizon: 12 weeks

\## ❓ Frequently Asked Questions



\*\*Q: Why are predictions decimal numbers (like 0.3 or 1.2)?\*\*  

A: These represent risk levels/probabilities. 0.3 means 30% chance of a crash. Think of it like weather forecasts.



\*\*Q: How far ahead can we trust predictions?\*\*  

A: Most reliable for 1-4 weeks. Use 5-12 weeks for general planning only.



\*\*Q: What should we do during high-risk weeks?\*\*  

A: Increase patrol presence, deploy resources to problematic areas, conduct targeted enforcement.



\*\*Q: Can I export the forecasts?\*\*  

A: Yes! Go to "Weekly Forecast" page and click the download button.



\*\*Q: How often should we retrain the model?\*\*  

A: Retrain monthly or whenever you have significant new data (3+ months of additional records).
